# Privacy Policy – Anna Text Summarizer

_Last updated: October 2026_

Anna Text Summarizer is a productivity app that helps users turn longer text into clear, concise summaries.

## Data Processing

Text entered into the app is processed only for the purpose of generating a summary.

The app uses Anna's native LLM runtime through the Anna platform and its Sampling capability.

Anna Text Summarizer does not use a separate third-party AI API key and does not independently send user text to an external model provider.

## Data Storage

Anna Text Summarizer does not intentionally store the text submitted for summarization in its own external database.

The app does not maintain user accounts, user profiles, or a separate analytics database.

Platform-level processing, logging, retention, and security are handled by the Anna platform according to Anna's own policies and terms.

## Permissions

The app requests the Sampling capability in order to generate AI-powered summaries.

This permission is used only for the summarization functionality described in the app.

## Third-Party Services

Anna Text Summarizer does not directly integrate with third-party advertising, tracking, or analytics services.

## Security

The app is designed to use Anna's native runtime and permission system rather than embedding external AI API credentials in the application.

## Changes to This Policy

This Privacy Policy may be updated if the app's functionality or data-processing behavior changes.
